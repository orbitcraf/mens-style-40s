# 40代男性のおしゃれ図鑑

40〜49歳男性が、季節・テイスト・シーン・パンツ・アウター・アイテム・色から選べる100コーデの図鑑です。各季節25件、6テイスト、7シーンを用意しています。Vite + TypeScriptで実装した静的サイトです。

公開サイト: https://orbitcraf.github.io/mens-style-40s/

## 開発

Node.js 22、pnpm 11.25.0を使用します。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

## コーデの追加

追加80件の組み合わせは `src/recipes.ts` に分離しています。各季節の配列に `[コーデ名, テイスト, シーン, トップスID, パンツID, アウターID, 靴ID, 帽子ID]` を追加してください。アウター・帽子を使わない場合は `none` を指定します。初版20件は `src/legacy.ts` に保持し、既存のIDと画像を維持しています。

`src/data.ts` には分類の定数、アイテム定義、着こなしの説明、画像指定、組み合わせを `Outfit` に変換する処理があります。新しいアイテムはここに名前・色・ブランド・商品カテゴリ・画像生成用の服装指定を追加します。各コーデは `top`、`pants`、`outer`、`shoes`、`hat` を明示的に持ち、アウター・帽子なしは `null` です。アイテムの名前・形・素材の組み合わせが色以外でも異なるようにしてください。

トップの6入口に各分類の件数を表示します。おすすめフラグは既存おすすめ4件と各季節の追加先頭6件です。パンツとアウターには主な形を1種類指定し、ベスト・シェルなどはアウターの「その他」に含めます。ワイドデニムは素材を優先し「デニム」、ワイドチノは形を優先し「ワイド」です。

一覧は隣接するコーデの季節・テイスト・パンツ・羽織りを比較して、違いが大きいものを先に並べます。初期表示は24件で「さらにコーデを見る」から追加できます。フィルター変更で24件に戻り、個別コーデへのリンクは必要な件数を自動表示します。

画像は `public/images/` に置き、`image` に `images/ファイル名.webp` を指定します。全身と靴が写った縦長2:3の画像を推奨します。表示はcontainを使い、全身を切り取らない設計です。画像と説明の服装・色が合っているか確認してください。

## ブランドと商品リンク

各アイテムの `brand` は類似商品を探す目安です。初期データはUNIQLO/GUの公式メンズ入口にリンクします。特定商品の存在・在庫を保証していません。実在する商品ページを確認できたら、各アイテムに任意の `productUrl` を追加してください。公式サイトのHTTPS URLのみを登録します。

商品画像は転載しません。100枚の見本写真は内蔵imagegenで生成した一般的な着こなしイメージで、実商品の写真ではありません。初版の生成方針は `IMAGE_PROMPTS.md`、追加80件の服装指定は各コーデの `imagePrompt` と `IMAGE_PROMPTS_EXPANDED.md` に記録しています。画像ファイルは各コーデのIDと対応します。

仕事コーデは私服・ビジネスカジュアルが許される職場向けです。雨の日コーデは服装の例であり、商品や生成画像に防水性能を保証するものではありません。購入時は職場のルールや公式商品の性能表示を確認してください。

## 公開

GitHub PagesのSourceをGitHub Actionsに設定します。mainへのpushでデータテスト・型チェック・ビルドを行い、distをPagesへ公開します。相対パスのbaseを使用し、リポジトリ名のサブパスから画像を読めるようにしています。

更新後はActionsの成功に加え、公開URLで画像、絞り込み、解説の開閉を確認してください。

## 動作検証

データテストで100件、季節ごとの25件、分類の網羅、ID・名前・色を除いた組み合わせの重複、画像の存在、公式URL形式、隣接コーデの変化、複数条件、おすすめ・羽織りなし、該当なし、リセットを確認します。ブラウザでは375px・768px・1440pxの幅で横スクロール、画像、6入口、複数条件、解説、追加表示、個別コーデへのリンク、キーボード操作を確認します。
